
# 需求文档

## Account

该业务预期为单用户的个人信息集合,包括个人信息,个人订阅两部分组成

需求概要
- 具有可登录性
	- 可注册
		- 注册要求 : 提供个人信息 ,个人订阅集合
		- 安全性要求补充 : 注册必须额外提供一个系统密钥用于过滤无效注册
		- 注册结果 : 返回一个随机生成的登录名
	- 可登录
		- 登录要求 : 必须提供 登录名 ,登录密码
		- 登录结果 : 返回一条token,用于提供给前端留存,进行后续业务的需要
- 个人信息
	- 个人网名
	- 个人 BIO
	- 个人头像 [依赖于File 业务]
- 个人订阅集合
	- 由一组订阅组成,可以没有订阅,即为空订阅
	- 订阅信息组成
		- 订阅平台名称
		- 订阅平台账户名
		- 订阅平台个人主页链接
		- 订阅平台 LOGO [依赖于File业务]
