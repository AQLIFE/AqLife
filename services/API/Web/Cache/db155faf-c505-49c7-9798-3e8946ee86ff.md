# `Element UI`

## 安装

> element-ui只支持2.6以下的版本，Vue3.0要使用element-ui就请使用element-plus

`CDN` 引入(使用该方式需要开发者提前引入`vue`语法支持,因为`element`是使用`vue`的`template`模板语法来进行组件解析的):

```html
<!-- 引入样式 -->
<link rel="stylesheet" href="https://unpkg.com/element-ui/lib/theme-chalk/index.css">
<!-- 引入组件库 -->
<script src="https://unpkg.com/element-ui/lib/index.js"></script>
```

在线引入的语法是可以正常使用的,但离线开发需要开发者自行下载文字和图标文件,并放置于`fonts`文件夹下,否则图标和部分文字将无法显示!!!

离线使用

`css`样式文件和`js`组件解析支持可通过上面`CDN`的链接进行下载(Copy).

[`ttf`文字文件和`woff`图标文件下载地址](https://unpkg.com/browse/element-ui@2.5.4/lib/theme-chalk/fonts/)

---

`Npm` 载入模块:

```shell
npm install element-plus --save
```

完整引入:

```js
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import App from './App.vue'

const app = createApp(App)

app.use(ElementPlus)
app.mount('#app')
```

## 语法

### 样式

`Element`语法以 `el`作为`html`前缀,并以`-`进行名称链接,即使用`短线命名法`.

该`UI`以`Layout`作为布局,每行24栏,也就是有最多24个`<el-col>`元素,每个`<el-col>`必须写在`<el-row>`内.

---

#### Container

| 名称           | 描述           | 属性        | 属性值                    |
| -------------- | -------------- | ----------- | ------------------------- |
| el-container | 顶级容器       | `direction` | `horizontal` / `vertical` |
| el-header    | 导航容器( 上 ) | `height`    | 默认为`60px`              |
| el-aside    | 目录容器( 左 ) | `width`     | 默认为`300px`             |
| el-main      | 内容容器( 右 ) | --          | --                        |
| el-footer    | 底部容器( 下 ) | `height`    | 默认为`60px`              |

> 对于`el-container`,它的子元素只能是后面四个;反之,这个四个(`el-header`,`el-aside`,`el-main`,`el-footer`)的父元素只能是`el-container`.

---

#### row

位于容器内的的行元素

| 属性      | 描述                       | 参数     | 参数值                                                       |
| --------- | -------------------------- | -------- | ------------------------------------------------------------ |
| `align`   | 组件内组件元素的排布 y轴   | `String` | `top \| bottom \| midden`,默认为`top`                          |
| `gutter`  | 组件内元素的排布距离       | `Number` | 默认为 `0`                                                   |
| `justify` | 组件内元素排列方式 x轴     | `String` | `Start \| center \| end \| space-around \| space-between` ,默认为`start` |
| `tag`     | 将该组件模板解析为指定标签 | `String` | 默认为`div`                                                  |
| `type`    | 指定组件类型               | `String` | `none \| flex`,默认为`none`|

---

#### col

位于`row`内的子元素

> 属性后期补充

#### icon

**图标**通过设置类名来使用,如:

```html
<i class="el-icon-edit"/>
```

> [官方图标列表大全](https://element.eleme.cn/#/zh-CN/component/icon)

### 组件

对于`Element`,其`Puls`和`Ui`版存在一定程度的语法差异,在文中需要时会标注出来.( 本文使用网页浏览顺序标注组件)

`Element Puls` 组件不能被`Vue`自定义组件包含嵌套!

#### 导航/菜单 | NavMenu

该组件通常写于整个网页程式的最上方,或者左边.是浏览者浏览时最先获取信息的组件.

| 属性                | 属性值                                                       | 版本支持                                    |
| ------------------- | ------------------------------------------------------------ | ------------------------------------------- |
| `mode`              | `horizontal` :这是 横向排列<br/> `vertical` : 这是 竖向排列,也是默认排列方式. | Element `UI` **√**<br/>Element `Plus` **√** |
| `background-color`  | 合法颜色表示                                                 | Element `UI` **√**<br/>Element `Plus` **√** |
| `text-color`        | 合法颜色表示                                                 | Element `UI` **√**<br/>Element `Plus` **√** |
| `active-text-color` | 合法颜色表示                                                 | Element `UI` **√**<br/>Element `Plus` **√** |

---

##### 折叠菜单 | SubMenu

两个版本语法差异在此:

| UI           | Puls          |
| ------------ | ------------- |
| `el-submenu` | `el-sub-menu` |

虽然版本语法不相同,但一些相关属性还是一致的:

| 属性 | 属性值 | 描述 |
| ---- | ------ | ---- |
|      |        |      |

#### 表单 | Form

| 表单主要构成   | 描述                  |
| -------------- | --------------------- |
| `el-form`      | Element form 表单元素 |
| `el-form-item` | 表单子元素(块)        |

表单主要元素

| 元素名              | 描述           |
| ------------------- | -------------- |
| `el-input`          | 文本输入       |
| `el-button`         | 按钮           |
| `el-radio-group`    | 单选组         |
| `el-radio`          | 单选按钮       |
| `el-select`         | 下拉列表       |

| `el-checkbox`       | 复选元素       |

##### el-form

作为所有表单元素的容器,这个是必须写于所有表单元素之前.通过该元素可以给表单内的子元素定义一些相关样式.

| 属性         | 描述                                | 参数      |
| ------------ | ----------------------------------- | --------- |
| `model`      | 绑定表单数据对象                    | `Object`  |
| `labelWidth` | 设置表单`label`宽度                 | `String`  |
| `inline`     | 设置表单排列方式,默认为真(竖向排列) | `Boolean` |
