# 后端技术笔记

## `ORM`

**对象关系映射**,（英语：**Object Relational Mapping**，简称**`ORM`**，或**O/RM**，或**O/R mapping**），是一种程序设计技术，用于实现[面向对象](https://baike.baidu.com/item/面向对象)编程语言里不同[类型系统](https://baike.baidu.com/item/类型系统/4273825)的[数据](https://baike.baidu.com/item/数据/5947370)之间的转换。从效果上说，它其实是创建了一个可在[编程语言](https://baike.baidu.com/item/编程语言/9845131)里使用的“虚拟对象数据库”。如今已有很多免费和付费的`ORM`产品，而有些程序员更倾向于创建自己的`ORM`工具。

- `Mybatis-puls`
- `Spring-Boot-Jpa`
- `Hibernate`

`Orm`数据库开发，能有效的减轻后端对数据库操作的压力，很好的简化了对数据库的相关操作。

整个开发只需要简单的 3 定义

- Bean 数据记录模型，其类属性对应数据库的字段
- Service 数据处理接口，通常继承 `ORM`的`CRUD`接口，如非必要，都不需要定义抽象方法
- 配置
  - 程序启动类使用`MapperScan` 配置为Service的路径
  - 接口控制器使用`Dao` 配置自动注入@`AutoWrited`

## `ORM` 支持

### `Spring-Data-Jpa`

依赖如下

```xml
<dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

特别支持：

- @Query  可通过该注解快速实现自定义查询，扩展性高
- @`EnableJpaRepositories`  通过引入 基于 `JavaConfig` 的存储库配置

---

### `Mybatis-puls`

依赖如下

```xml
<dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-boot-starter</artifactId>
            <version>3.5.0</version>
</dependency>
```

CRUD 支持

- `Iservice` 通常用于键值对等非关系型数据库
- `BaseMapper` 通常用于关系型数据库
