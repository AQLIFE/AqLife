# c语言编写的注册登录功能模块

有三个功能子项：注册、登录、退出。

> 没有按照明确的功能模块来进行功能规范的设计，且包含对菜单项的隐藏描述

具体要求：
1。菜单项只能输入数字1，2，3，如果输入不是这些，提示“菜单功能项输入错误，请重新输入....”，然后回到主菜单。

> 对于数据的对应功能点没有描述清晰、完整

2。如果用户名输入格式中无 @，则提示“@必须出现，且不能在开头位置”，然后重新输入；如果用户名输入格式中无 .，则提示“.必须出现，且不能在开头位置”，然后重新输入；

> - 这条需求项没有明确和数据的关系，无法直接得知使用何种数据执行该操作；
>
> - 条件不够清晰，包含隐式条件；
>
> - 和后文描述需求有冗余描述，需要进行描述整合。

3。输入2进入登录功能，如果用户名输入格式中无@，则提示“@必须出现，且不能在开头位置”；如果用户名输入格式中无 .，则提示“.必须出现，且不能在开头位置”；如果输入的用户名不正确或者输入的用户名未注册，出现错误提示，“用户名输入错误或用户不存在。”。如果输入的用户名正确，并且密码也正确，则出现“登录成功！”提示；如果输入的用户名正确，并且密码不正确，则出现“密码不正确！！”提示。

4。输入3 结束应用程序。

5。注册和登录时的用户名格式要求，长度不能超过20位字符，必须输入英文的@和.，并且@和.不能在第一位，.在@后面。

6。注册和登录时的密码格式要求：长度不能超过10位字符。

7。合法格式的用户名和密码注册成功后数据保存在rg.txt文件中，并且可以追加保存。

8。密码输入时必须以“*”形式显示。

9。登录的用户一定是已经注册成功的合法用户。

10。输入1进入注册功能，如果用户名输入格式中无@，则提示“@必须出现，且不能在开头位置"
